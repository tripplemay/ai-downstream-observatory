# 长期资金路径：完整窗口、持有对照与滚动风险

状态：2026-10-08，本地实现及最终全量回归通过，桌面/手机 headless 交互通过，未部署。真实来源、原生/用户视觉及生产验收仍待完成。本文不包含个人金额、账户或凭据。

## 使用

在[长期投入比较](20-private-funded-comparison.md)完成后台计算和汇总核验后，每个可核验候选可点击“查看完整窗口曲线与持有对照”。选择及时释放或预定三批只改变查看路径，不保存资金安排、选择个人权重或授权交易。

- **资产与本金**：候选人民币净资产、累计本金、等待释放现金、持有对照净资产分别展示。
- **累计盈亏**：已识别成本后的净资产减本金，追加本金不算投资收益。
- **单位回撤**：资金流中性的单位净值回撤，不因追加本金掩盖损失。
- 滑块查看每个已观测估值日的精确金额；图形坐标仅作显示，不能作会计或成交计算。

没有冻结候选、留存载荷、当前来源或可重放经济字段时，不显示曲线。失败候选仍保留在原比较中，不因无法画图从列表删去。

## 计算口径

1. 沿用同一个连续账户、原完整历史窗口与原资金流，不缩短年份、不拼接年度重启账户，也不选择收益更好的历史起点。
2. 图形保留每个**已观测当地日期的最后模型估值点**，覆盖整个窗口；不是每天都有报价，不填补缺失日期。估值包含模型现金、交收和理论除权承接，不宣称每个点都是实时报价。连线只为阅读，不代表中间价格或可成交价格。
3. 最大回撤、峰值/谷底、恢复及最长峰下区间在**全部模型估值点**计算，然后才压缩日末图。因此图上日末浅回撤不能替代全估值点最深回撤。
4. “谷底恢复”表示最深谷底到重新达到原峰值的当地日历天数；“最长峰下区间”从该区间峰值起算，可能不是最深回撤区间。未恢复明确标识；日历天数不是交易日或四舍五入后的 UTC 小时数。
5. 滚动统计使用相隔 12/36/60 个**日历月键**的最后已观测单位净值之比，要求中间月份都有观测。不用 365 天代替一年，不把缺月跳过去；13 个连续月末点才构成首个 12 月窗口。一年历史仍可有整个窗口的 TWR，但不据此伪造一年滚动窗口。
6. 亏损次数和占比是这份历史中重叠窗口的样本统计，不是未来亏损概率，窗口也不独立。历史最大回撤不是未来损失上限，历史恢复不是未来恢复保证。

## 持有对照不是独立预注册基准

对照使用同一候选的 ETF、权重、到账、分批、历史、FX、交易单位、公司行动、费用和税务假设；只关闭周期及类别偏离触发的买卖再平衡。首次建仓、释放的新人民币现金及已支付人民币分红仍按原规则不卖出补低配。外币分红仍留在原币种；等待现金不新增假设利息。对照不会卖出，也不以未来收益改变配置。

因此它是**本次回顾性反事实**，不是已独立预注册、未曝光的策略基准，也不是固定份额“一次买入后再不买”的模型。界面同时展示候选减对照的净资产、TWR 差及对照成本与执行缺口；不保证候选胜出，不把结果排名当作个人配置建议。真实简单基准、宇宙、资料许可、样本外资格和税费完整性仍待验收。

原 Python/Node 引擎默认行为和旧合同不改变。持有模式只是内部明确 opt-in；新 GET 不允许客户端提交该开关、权重、历史、原始 JSON 或算法参数。

## 私有只读接口与资源边界

`GET /api/workbench/investor/funded-analysis?candidate=<当前冻结参数哈希>&path=immediate|staged`

- 先认证、核对会话绑定，再严格校验两个唯一查询项；不能指定所有者、工作区、数据库或文件路径。
- 从当前所有者的偏好/资金/任务/运行及有效审阅来源选择候选。固定 Node 子进程先独立重放并核对原两条路径的经济摘要，再生成选定路径及持有对照。
- 子进程不读取凭据，不访问数据库、SDK 或网络；固定构建与源文件清单前后复核。输入最多 18 MiB，分析输出最多 8 MiB，JS heap 384 MiB、时限 60 秒；普通汇总输出仍限 64 KiB。
- 与原汇总共享每进程最多两项、同工作区一项容量；这不是跨副本准入或生产负载 SLA。完整估值最多 100000 点，日末最多 3670 点，月末最多 121 点，超限拒绝、不截断。
- 重放后再次核对全部私有版本和来源；认证路由再核对会话及到期。变化或取消不返回旧经济数据。GET 不登记任务、不清理载荷、不写偏好、账本、批准、预占或执行。
- 浏览器检查会话/范围/候选/路径、已核验摘要、金额守恒、曲线摘要、月末与滚动重算、风险时间及对照差值。路径/版本变化立即隐藏旧曲线；过期/撤回仍由父比较状态保护。摘要验证不认证原始供应商数据或旧 Python 轨迹。

单个路径及对照无执行缺口才标识该项经济字段已独立重放；不升级整个研究或失败同伴。`source_independently_verified`、参数预注册、原轨迹摘要认证、实际到账、publication、live-advice 和交易授权始终为 false。
