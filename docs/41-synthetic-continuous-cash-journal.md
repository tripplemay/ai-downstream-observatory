# 连续现金、持仓与合成研究事件库

## 状态与边界

本阶段将文档 40 的无状态限额买入原语串成可连续重放的模型账户。
这是独立、仅合成数据的开发链路，不是生产资金账本、完整策略回测或可采用组合。

- 协议：`bounded-cash-journal-sandbox-v1`；独立契约为
  `contracts/v1/bounded-cash-journal.schema.json`。
- Python 状态与本地存储：`worker/execution_sandbox/journal.py`、`journal_store.py`。
- Web 独立状态复算：`web/src/server/execution-sandbox/journal.ts`。
- 没有修改旧研究内核、旧结果契约、实际账本、schema migrations、worker 命令、
  HTTP/API 或 UI。不连接券商、行情供应商或外部 AI。
- 所有输入都明确为 `synthetic_test_only`；真实数据资格、实盘建议和独立预登记
  不能由本协议授予，相关声明固定为 false。

## 完整的最小链路

1. **声明**：固定政策、版本和源代码身份，建立零现金、零持仓状态。
   `registered_at` 是合成情景中的逻辑时点，不是对历史真实预登记的证明。
2. **资金投入事件**：正值人民币金额、唯一投入 ID。没有预计到账或未交收购买力。
3. **冻结批次**：决策时点、现金快照、全部其他挂单的预算必须与前一状态一致。
   同一研究中的批次 ID、订单 ID 不可重复使用；原语独立核验数量和费用。
4. **连续追加**：有挂单时可以继续投入现金；已有预算锁定不被覆盖。
5. **终态处理**：指定批次在其终态时点独立复算，实际扣款只作为当前现金的增量。
   **不能把该批次决策时的旧余额快照直接替换当前余额**。
6. **累计持仓**：只对模拟执行成功的冻结数量增加持仓；缺失/超界等失败累计保留。
   终态后释放该批次未消耗预算，不扩大其他冻结订单。

已到终态的批次必须先处理，再接受后来资金或决策。多个批次按最早终态顺序
处理，避免跳过待处理执行而继续使用陈旧状态。执行价格仍只是指定下一时点的
合成收盘代理；持仓/扣款在终态事件处理时入账，**没有声称模拟真实成交和交收时点**。

## 不可变记录与重放

每一事件保留命令 ID、逻辑时点、序号、前驱事件 hash、前后状态 hash 和完整
输入/冻结计划/执行结果。事件数据和状态都通过闭合契约，再实际重放经济行为。

- 两端独立更新现金、锁定预算、持仓、已用 ID 与累计失败数，不仅比较 hash。
- 重新封印错误数量、余额或状态不能绕过复算；事件顺序和时点不能倒退。
- 政策或实现身份变化时必须建立新研究声明，不在旧历史上偷偷换版本。
- 旧研究须用归档的兼容源代码和依赖重放；当前实现身份不匹配时停止投影，
  不靠修改旧声明继续使用新代码。本阶段的源码基线和新增差异单独私有归档。
- 类型化状态是投影，不是另一个可修改的事实表；从声明和事件重新生成。

## 独立本地 SQLite 存储

存储没有使用主工作台的数据库或迁移机制：

- 只接受绝对路径 `*.sandbox.sqlite`，父目录须私有，文件须为本人所有的私有
  普通单链接文件。拒绝符号链接、硬链接、开放权限、外来非空数据库，以及
  工作台、旧观测站和认证数据库的文件名。
- 数据库有独立 `application_id` 和版本。声明及事件只允许追加，SQL 触发器
  阻止 UPDATE/DELETE，并检查事件顺序和前驱。
- 写入使用 `BEGIN IMMEDIATE` 和调用者提供的 head hash。两个写者从同一 head
  发起不同命令时，至多一个成功；另一个获得冲突，不重复消费同一现金。
- 相同命令 ID、相同内容的重试只返回旧事件与**当前最新状态**，不重新扣款。
  相同 ID、不同内容阻断；写入故障回滚后可以用同一命令重试。
- 关闭、重新打开数据库后，完整读取并重放验证每一条记录。它不是生产备份恢复。

哈希链和本地触发器不是数字签名、独立审计或防数据库所有者篡改的认证。
完整删除合法尾段后，剩余前缀仍可能有效；可通过另行保留的预期 head 检查
这类截断，但同机保存的 head 不是独立故障域或可信第三方见证。

## 测试与资源边界

手算链路包含两个重叠批次、之后追加的现金、两次扣款、累计持仓及释放预算。
额外覆盖缺失报价、陈旧快照、政策/ID 复用、到期处理顺序、微秒倒退、重封印
篡改、SQLite 真实双写者、故障回滚、重试、重开、权限/外来库拒绝和尾段截断。
还有 32 组合成连续情景的 Python/Web 独立重放。

单研究最多 512 事件、20 个证券、20 个开放批次，本地序列化记录有 32 MiB
上限；旧原语的订单/已有预算数量限制继续有效。未完成满载或长时间性能验收。
测试费率、预算、价格和数量步长均为虚构软件向量，不是推荐参数或市场权限证明。
