# 真实组合对照：记录快照与研究目标

状态：本地研发能力，尚未发布。只读算术对照，不是实时券商同步、账户盈利报告、买卖清单或交易授权。

## 用户路径

1. 不导入账户也可研究并保存参考方案。需要对照自己的资产时，在“账户资料”显式关联私有账本，选择或建立账户；建档不生成现金和持仓。
2. 通过流水入口核对已发生事实；少量已执行交易可在账户页[人工成交回录](27-manual-executed-fact-recording.md)，交收现金另据实际资料记录。再在“独立对账”按券商账单或其他独立资料转录并提交。导入或回录成功不等于对账完成；全部账户均需对账，停用账户不能被静默排除。原件上传、详细差异和估值仍在“高级账本”。
3. 完整人民币估值通过复核后，“真实组合对照”展示截止日期、账本版本、覆盖账户及整个组合构成。只有研究方案有效、证券身份经审计映射且审查有效时，才展示目标算术偏差。缺少条件则显示具体待办，不补造数字。

## 数字的含义

- 净值分母包括全部已记录现金、外币折算、应收、带符号应付和负债、非目标证券，以及证券转移在途。证券在途只计入一次，不同时算作来源与目标账户的持仓。
- 所有金额展示均为人民币折算；资产的币种标签不改变展示金额的口径。证券数量另显示已入持仓与转移在途数量。
- 实际权重为资产人民币价值除以整个账本净值，不将目标 ETF 单独归一化。
- 金额偏差为实际价值减去整个账本净值乘以目标权重；权重偏差为实际权重减去目标权重。正数表示高于目标，负数表示低于目标。
- 目标以外的净资产包含现金、非目标证券和负债，可能为负。它不是可以立即投资的可用现金。
- 净值不是盈利。模型收益、实际账户损益和新增本金仍分别处理；本页不新增账户绩效计算。

## 来源与失效

服务端重新读取有所有者审计的对账记录和私有附件，检查哈希、账户范围、资料审计不晚于对账、当前事实、未决差异与完整估值。结构化入口留存的是用户转录的 JSON，不是券商原件；它核对用户提供的资料，不能证明资料直接来自券商，也不能发现尚未回录的交易。同一时刻有多条最新对账时，不按随机 ID 任选一条作为匹配证明。

研究 ID 与账本 ID 不必相同，但必须通过唯一、经审计、当前有效的明确证券映射对应。不能仅凭相似名称、代码后缀或挂牌市场猜测；映射冲突和重复分配会隐藏对照。

页面读取不创建事实、不重新估值、不安排任务、不激活账户、不批准或下单。会话、关联、账本版本、账户覆盖和研究版本必须一致；客户端另复核总额、权重及研究目标绑定。新的账户事实使旧快照失效，先重新对账和估值，而不是继续显示旧数字。

可见页每 30 秒只读复核；账户核验、未决导入或会话未确认期间暂停数字显示。读取失败不显示旧值。研究对照到期后隐藏目标偏差，历史记录快照仍只能代表其截止日期，不因此成为当前价格或交易依据。

## 结构化独立对账

1. 先核对私有账本与导入账户，再点“录入独立资料”。范围读取只列出币种、证券身份和在途标识，不预填金额或数量。缺证券目录时先登记明确身份，不用相似名称猜测。
2. 输入独立资料编号、截至日期和原件时区。日期表示该地完整一天，转换为下一日当地零点的 UTC 边界，纽约夏令时按实际日历处理。不支持拿旧账单与含有其后事实的当前余额比较，也不伪造盘中时点。
3. 逐币种填写现金及其他七类金额，逐证券填写数量，逐在途记录填写数量。只有已逐项核对其他七项确实全为零，才勾选该币种的零值简化项；它不代替证券或在途数量。负债等沿用系统带符号口径，不确定时先核对，未知不等于零。
4. 完整覆盖确认后保存。任何内容变更会撤销确认；草稿期间暂停本页的其他写入口和范围切换。取消会清除草稿，退出/会话失效清除私人表单。匹配不会补造现金、调整持仓、生成估值、批准或执行交易。
5. 新资料匹配不自动解决旧差异。必须明确选择经过原始资料复核的旧差异，填写原因，并使用不早于旧截止时点的完整匹配资料；否则保持未决状态。旧资料丢失或审计损坏时隐藏旧匹配结果，仍允许新独立提交，但本入口不能清除未经复核的旧问题。
6. 如提示“提交仍待核对”，只读刷新不代表已恢复。使用“核对并重试原请求”核对同一请求，不能改内容重发；已有受理请求通过幂等收据去重。恢复锁下拒绝新写入和旧请求重试。

单次最多 20 个币种、100 项证券、30 项证券在途；范围最多 200 项证券身份、100 项未决差异。请求最多 32 KiB UTF-8，超限明确拒绝，不截断成“完整”账单。来源只存私有目录，不进入公开仓库。

资料、对账、审计与收据在同一数据库事务提交。文件系统不参与 SQLite 事务；晚期数据库失败可能留下权限为 `0600` 的未引用附件，不能将数据库回滚称为物理附件清除。失败不会留下对账、收据或金融事实；遗留文件清理仍需受控治理。
