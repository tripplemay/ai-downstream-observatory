3. **真实研究**：沿用已批准来源/用途/请求边界；不自动重跑失败试验、重选
   参数或把已曝光保留期改称独立验证。策略资格与软件验收分开。
4. **发布前只读盘点**：准确 main SHA、环境保护、固定 SSH 信任、服务/模式、
   容量、迁移/真实副本恢复和回滚边界按当前证据复核。不沿用九月配置清单

   不捎带删除资源、购买存储或改交易授权。核对版本/schema、未登录拒绝、
   登录后真实业务、后台任务与数据质量；外网 200 仅是连通检查。
