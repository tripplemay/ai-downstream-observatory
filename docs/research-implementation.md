# 策略研究与 AI 边界：首个实现切片

本文件记录实现范围，不修改 `03-decision-policy.md`、`06-validation-and-acceptance.md` 的批准状态。

## 已实现的闭环

`冻结发布数据 → 预登记计划/参数 → 训练 → 验证 → 人工冻结候选 → 人工解封 → 单次留出评估 → 只读 AI 审阅`

代码：`worker/research/`；共享输入契约：`contracts/v1/research-*.schema.json`；AI 输出契约：`contracts/v1/ai-research-review.schema.json`；追加迁移：`migrations/0007_research_experiments.sql`。

首个策略只研究固定权重下的现金投入：新增现金修复低配、固定比例投入、分批等待现金，与同资金到账日、同成本/FX/执行条件的基准比较。记录净值、现金流利润、TWR、XIRR、回撤、费用、现金比例与完整模拟事件。

## 已验证的工程边界

- 决策后下一收盘成交，不能获得选样日已经发生的涨幅；未来价格不能反过来决定当时订单数量。
- A 股决策时看不到尚未发生的美股收盘；实际回放看不到当时尚未摄取的数据。
- 发布版本固定、快照/参数哈希可验、终态结果不可改，模拟事件与真实账本隔离。
- 试验次数与失败尝试保留；候选冻结后不能继续搜索；留出窗口不能重叠、不能未解封运行，且仅允许冻结参数运行一次。
- 缺行情、FX、公司行动覆盖或历史可交易证据时不生成补造结果；税费和现金精度显式处理。
- AI 不能把字段、自然语言或 SQL 文本变成真实记账、批准、激活或交易动作；来源引用与数字逐项核对。

## 未完成及不能推断的事项

- S-01 至 S-10 没有任何一项因本模块而自动通过；合成数据、成功 JSON 和计算通过都不是实盘准入证据。
- 无独立核验的真实历史档案/全市场幸存者偏差控制，无已批准的真实券商成本、税务与账户权限模型。
- 无完整资产配置优化、卖出再平衡、税损收割、多组合复杂结算或自动交易；当前三个窗口独立重启，不可拼成十年真实业绩。
- 留出集流程没有加密隔离，不能证明人类未事先查看；跨不同但近似数据集的隐蔽重试也尚不能自动识别。
- 未自动完成参数稳定性/成本敏感性全矩阵、统计显著性、多阶段真实样本外验证或持续前瞻模拟；研究结果不保证持续盈利。
- 未接入真实模型或外部研究数据提供商。真实 provider 超时、隐私许可和模型版本仍需部署配置与专项验收。

操作步骤、API 和调度接入边界见 `worker/research/README.md`。

## Web 入口

`/workbench/research` 提供实验/试验摘要、同口径基准、冻结解封记录、AI 留档与后台任务回执。
命令通过已登录的 `/api/workbench` 提交，研究载荷仅采用共享契约；身份、组合范围与账本版本由请求上下文限定。
当前先支持标准 JSON 载荷界面，不预填投资参数。修改载荷、切换组合会取消原人工确认；重试沿用同一语义命令的幂等键。

实验和试验的实现哈希在实际执行 Worker 内生成，不能先在另一台主机注册再假定相同环境执行。
AI 命令只生成证据输入、校验并留存外部模型文本；填写 model 名称不代表系统实际调用了该服务商。
