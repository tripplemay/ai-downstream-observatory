# 站内研究通知

## 用户路径

工作区右上角的“研究通知”查看最近发布的模型监测记录，无需建立券商账户、录入持仓或填写 JSON。

- 点击“查看观察记录”进入观察页；那里独立核对当前结论、来源、有效期及变化卡。
- “标记已读”只记下读过这条消息，不表示采纳方案、批准交易或确认成交。
- 目前显示最近 20 条，未读数字只针对这 20 条，不是全部历史未读总数。更早观察仍留在数据库；观察页本身也有历史显示上限，并非完整归档检索。
- 页面可见时每 60 秒核对通知，刷新和轮询只读取；不启动研究、AI 或任何交易。关闭页面不会产生推送。

这是历史发布收件箱，不是实时告警系统。通知中的“继续观察 / 需要人工决策 / 证据不足”明确标为**记录状态**，不能替代首页的当前有效结论。来源撤回、到期或载荷清理后，可以保留历史元数据，但不能把旧消息解释成仍有效的建议。

## 发布与已读边界

仅接纳 core 已原子提交的 `investor_evidence_monitor_runs`、观察引用、成功任务及对应 `investor.observation.changed` outbox 元数据。初始数据缺口、未保存的研究候选、失败/跳过任务和普通 synthetic 预览不能凭空生成此类通知。

已登记 epoch 的首个暂停状态刻意不发布 outbox，因此不伪造一条“研究已更新”消息，
也不占用最近 20 条通知的位置。后续真实发布使用 `epoch-continuation:<publication_id>`，
与旧监测的 `investor-monitor:<run_id>` 分别核对；不能把新协议套入旧作业结果形状。
最近原始头中的暂停首状态仍须核对真实登记、作业及状态元数据，不能捕获错误后跳过。
后续通知另核对真实 journal、请求、成功 attempt/fence 和确切结果，不读取价格或
检查点经济载荷，也不由历史绑定推导当前来源准入。

读端核对所有者、工作区、模型/观察/任务引用、严格关闭的 payload、记录摘要及发布时间。研究头使用毫秒、Python outbox 使用微秒；通过精确补零绑定同一发布时间，不截断非零微秒、不采用近似浮点时间比较。损坏或缺失绑定返回不可用，不混入部分“正常”消息。

通知只返回闭合元数据，不返回报价、金额、风险答案、持仓、账户、来源原件或 AI 正文。验证的是历史发布绑定，不重放当前市场资格，也不授予 `live_advice_eligible`。

迁移 40 只追加查询索引和已读保护：

- 已读在既有 append-only `audit_events` 中独立登记，同所有者/通知唯一；重复点击或另一数据库连接再次确认复用同一收据。
- 审计 payload 仅为工作区 ID 与发布摘要；不绑定金融 portfolio/revision。
- 不修改工作区 revision、模型、观察、决定、账本、任务、AI 请求或 outbox 状态/投递次数。
- 恢复锁允许读取历史元数据，拒绝已读写入，包括重复确认。
- 没有回填旧行，没有创建通知内容副本，也没有宣称删除 WAL、备份或物理介质上的历史记录。

迁移 68 仅替换已读插入保护，使真实后续发布能登记同一格式的已读审计，并拒绝给
暂停首状态伪造的消息登记已读。迁移 1–67 不变；不新增表、不复制通知或行情，不回填
旧审计，不更改控制和金融事实。失败升级原子回滚，已有已读、原行/rowid 及旧迁移
校验和保持不变；这不是资料清理或业务备份操作。

## 接口与交互保护

`GET /api/workbench/investor/notifications` 读取最近 20 条及可见未读数。`POST` 只接收 `notice_id` 与 `publication_hash`，登记已读。

两者先认证并要求会话绑定，拒绝查询参数；写接口另外要求同源、严格 UTF-8/无重复键 JSON 和 1024 字节上限，读取请求后再次认证。所有者由服务端会话确定；响应不可缓存，底层路径、原件和堆栈不回传。

面板取消旧作用域请求，退出登录关闭并清空弹窗；旧请求的迟到 401 不能锁住新作用域。当前 401 通知整体会话边界重新核对。未知的已读提交不推定失败，不自动重发 POST；自动或人工 GET 可以重新核对。只读/恢复模式仍能查看，但禁用已读按钮。

最近记录查询使用工作区/发布时间/ID 索引，先选择最多 21 个原始头核对近期暂停首状态，
再选择最多 21 个非首状态候选，返回其中 20 条；两个选择合计最多 42 个头。
SQL 排除已绑定的暂停首状态，未绑定、缺失或协议不一致的候选仍报不可用，不返回部分
健康列表。已读查询使用专用部分唯一索引；不全表统计历史未读。选择数量不是数据库
扫描/CPU 的绝对上限，也不证明所有远古首状态完整或十年负载合格。

```sh
WORKBENCH_TEST_PYTHON=/absolute/path/to/test-python node scripts/verify-investor-notifications.mjs --temporary-root /absolute/external/temp-directory
```
