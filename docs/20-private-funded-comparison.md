# 私有长期投入比较任务

状态：2026-10-08，本地研发纵切；已连接认证登记、后台计算、限期私有留存、按需独立重放与结果界面，未部署生产。全部验证使用虚构来源，不是投资策略有效性证明。个人金额、券商和凭据不进入本文。

## 1. 使用路径

1. 保存研究偏好；风险可以继续保持未知，不必先建账户。
2. 在“长期投入安排”填写并保存私有日期化计划。
3. 点击“比较及时投入与有限分期”。系统绑定当前偏好、投入版本和研究来源，不要求上传 JSON、选择算法参数或手工设置历史起点。
4. 查看排队、运行、重试、条件不足、失败、过时或等待独立核验的状态。缺少资料时保留具体缺口，不生成示例权重或预期收益。
5. 后台有完整历史候选结果时，点击“查看已登记的比较结果”。无需提供 JSON 或算法参数；独立经济字段重放通过后才显示两条路径的假设本金、净资产、已识别成本后盈亏、等待释放现金、现金比例、TWR/XIRR、年化和单位净值回撤。失败候选仍保留，不排名或自动选取个人配置。
6. 每个可核验候选可按需展开[完整窗口曲线、持有对照与滚动风险](22-funded-path-analysis.md)。路径切换只影响查看，不改变已保存计划；资料过期或变化隐藏旧曲线。

保存投入计划本身仍不排队计算。只有上述明确比较动作创建独立请求；刷新和轮询只读。比较不会调整参考方案、启用监测、改变风险答案、登记到账、写真实持仓或创建订单。

## 2. 固定研究边界

- 请求固定工作区、偏好/资金版本与哈希、来源头与受审阅输入、实际服务端登记时间。客户端只能提交动作、CAS revision 和幂等键，不能提交数据、参数、结果、风险授权或历史日期。
- 只有当前有效的受审阅重建来源可进入计算；合成输入和零散行情不能替代来源。来源资格仍是所有者审阅，不是供应商许可或历史发布时间的独立认证。
- 比较全部冻结的低频 v2 候选，最多八项，按参数哈希排序。混用旧规则、重复候选或时区冲突明确阻断；不在风险未知时选出个人权重，不按未来收益删选候选。
- 用款不明确、排除项尚无合格目录、来源超出允许市场、期限不符合策略范围或所选轮动证据未就绪时明确阻断；绑定偏好哈希不替代实际遵守偏好。不会为了运行计算而扩大市场或忽略限制。
- 历史窗口选取规则固定为来源范围内**最早能完整容纳整个投入期限的同月同日起点**。所有到账日期整体平移整数年；不按价格/收益选择起点、不改变月日、不缩短期限、不拼接独立重启账户。非法闰日平移不能用相邻日期偷偷替代。
- 参数记录时间来自受审阅来源，比较登记与信息截止来自本次请求时间。它是当前登记的回顾性探索，不是过去的预注册或未曝光保留期。原数据中的 `assumed_available_at` 保持为重建假设，不伪造成供应商 `published_at`；所有实际摄取时间也必须不晚于截止。
- 两条资金路径共用配置、到账、日历、价格、成本、决策和交收，仅资金释放节奏不同。批次释放不代表成交，60 个自然日不保证完成投资。费用/税务假设仍需真实核验。

## 3. 持久化与失败

迁移 36 只追加 `investor_funded_study_requests` 和 `investor_funded_study_runs`，不改旧迁移和经济合同。请求与运行不可变；请求在读取经济结果前登记。core 使用现有作业 attempt、有限重试、租约、心跳与 fencing，计算在写事务外，短事务提交运行及工作区 revision。

偏好、资金版本、来源、保留期限、实现或租约变化会阻止旧结果提交；恢复锁出现时提交整体回滚。正常比较中的失败候选保留在同一候选列表，不只留下成功项；系统级中止/失败保留请求和作业尝试。行情 provider worker 不发现、认领或执行此任务。

迁移 37 将结果头、最多 1 MiB 的派生经济结果 BLOB、审计清理记录分表保存。原始行情不复制；头及哈希不可变，BLOB 不可覆盖，只有所有者绑定的清理审计记录允许删除。结果上限等于原来源最早保留期限，不能延长原许可。旧作业只有摘要时明确提示重新比较，不伪造结果或静默补算成历史证据。

core 每次正常发现循环按批检查到期、审阅更新/撤回与行情载荷清理，重新核对所有者和失效来源后审计删除结果 BLOB；恢复锁阻止清理提交。GET 不触发清理、采集、作业或金融写入。清理是 SQLite 逻辑删除，不宣称 WAL、备份和介质已物理擦除；备份留存和真实许可仍须生产治理验收。core 停止时不能承诺定时清理，过期结果仍不会显示。

## 4. 不能把计算完成当成结论有效

`calculated_unverified` 仍只表示后台完成了受控计算，不能据此显示收益。独立 `GET /api/workbench/investor/funded-comparison` 首先认证和检查会话绑定，不允许查询参数或客户端范围；从本地审计来源重建冻结候选输入，再通过固定 Node 子进程重放经济字段。子进程不连接数据库、SDK、网络或凭据，输入/输出/内存/时限有界；每进程最多两项、同工作区一项请求，不能视为分布式或满载 SLA 验收。

固定构建包及源文件清单在调用前后核对；核验后重新读取私有版本、来源有效期和会话。任一变化不返回旧经济字段。普通五秒状态轮询不执行此重放；界面独立请求响应也须通过会话/工作区/revision/偏好/投入/任务绑定校验，过期或版本变化隐藏。原接口仍只显示汇总，另一个按需分析 GET 提供完整窗口日末曲线及全估值点风险，不认证真实行情资料。

旧请求/运行/任务合同仍固定原五项 false。新私有比较合同仅在全部候选独立重放通过且无模拟执行缺口时返回 `economics_independently_replayed=true`；部分成功逐项标识，整体保持 false。新结果始终保持 `source_independently_verified=false`、`parameters_independently_preregistered=false`、`engine_trace_hash_independently_certified=false`、`actual_arrivals_confirmed=false`、`publication_eligible=false`、`execution_authorized=false`、`live_advice_eligible=false`。派生字段核验不等于来源许可、历史预注册或投资有效性。

下一步接入真实小型 ETF 宇宙、多年资料、独立基准/样本外风险资格，再完成持续更新、AI 解释、监测提醒及实际账户回录。新持有对照是回顾性反事实；已接入的损失金额情景、风险确认与滚动展示不能替代这些资格。不得以虚构来源测试通过宣布个人长期方案或生产上线。
