# 总览中的当前研究模型

状态：研发实现，未发布。补齐 v2 首屏的“正在观察什么、与参考目标差多少”，不改变策略、监测准入或交易权限。

## 用户看到什么

有合格监测结果时，总览先展示“当前研究模型”：每只 ETF 的模型当前权重、参考目标、
带方向的百分点偏离、人民币折算模型市值，以及该市场自己的收盘截止时间。总估值
明确以初始 10,000 CNY 归一化，不是用户本金、账户资产或实际投资收益。

权重分母仍是包括模型现金、外币和应收的整个模型估值。ETF 权重不重新归一到 100%，
也不把估值余项称为可用现金。计划追加、假设修复后的目标金额和“采纳思路”均不会
进入当前构成。偏离只是状态，不是新的买卖信号；需要决定时仍由原变化卡解释成本、
风险、反对理由及尚未核验事项。

当前模型合格时，原历史参考卡放在可用键盘展开的“历史参考配置与研究依据”中。
首次尚未保存、尚无监测输入或证据不足时不采用这种折叠，继续优先展示原参考或具体
缺口。组合方案页保留完整参考卡，并另列合格的当前模型，不隐藏初始方案的依据。

## 数据与失效边界

- 仅消费既有独立重放后的监测结果字段，不增加 API、行情请求、计算任务、账户或写入。
- 当前已保存参考、偏好、模型、观察和监测输入版本必须一致，来源资格及结果状态有效。
  只有 `research_observe` / `research_decision` 可显示；历史研究、合成预览和未完成任务
  不升级为当前模型。缺少一只标的、目标绑定、行情截止或模型估值一致性就不显示该卡。
- 使用 `current_model_value_cny` / `observed_model_weight`，不使用假设投入后的目标市值，
  也不从拟调整金额反推当前持仓。所有币种市值都明确按人民币折算展示。
- 权重差用十进制整数精确相减，展示才舍入；微小非零偏离和小于分币的正市值明确显示
  `<0.01`，不显示为零。原监测精度、阈值和策略判断不变。
- 沿用现有保守显示时钟。观察、模型或来源到期时，即使编辑锁住刷新也隐藏当前卡；
  时钟回拨不能恢复旧显示。提交结果不明、会话未确认或失效期间不显示为当前模型。
  历史观察仍保留，不因卡片隐藏而删除或重新采集。

## 验收范围

显示合同测试核对现金/应收分母、计划资金隔离、逐项绑定、精确偏离、到期和未知提交；
既有默认 core 的观察与新资金决策结果也接入同一显示投影，保持金融事实零写入。
真实来源、完整三态原生流程、性能/恢复和受保护生产发布仍需独立验收；组件显示通过
不认证策略盈利或十年可用性。
