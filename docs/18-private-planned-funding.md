# 私有长期投入安排

状态：2026-10-09，本地表单、持久版本、计划日期算术、按需历史比较及年度计划的默认 core 接入已实现，虚构来源的限定冻结回归通过。不是到账事实、收益预测或生产发布。个人金额、日期及券商资料不进入本文。

## 用户路径

先保存简短研究偏好，不需要创建账户。在总览或组合方案的「长期投入安排」选择「填写投入安排」，填写开始日期、初始计划本金、每年追加及第一次追加日期，核对期限、日历时区和资金进入路径后保存。该步骤可跳过，不阻断先研究参考组合，也无需提交 JSON。

- 支持最多十个当地日历年，且不超过当前研究偏好的期限。
- 年度追加按第一次追加的同月同日展开；开始日可以同时有初始计划与第一笔年度追加，明确分列，不重复统计。结束日不含在窗口内。
- 无追加时填写 0，年度日期不使用；有追加时，首次日期必须在计划期内。真实日历日期严格核对，不能静默把闰日改成其他日期。
- 本版计划日历可选上海、香港或纽约；只是计划日期，不是当地交易日历、实际到账时点、有效收盘或可以交易的证明。
- 进入路径可选及时释放或第 0 / 30 / 60 个自然日三批。金额精确到分，向下等分后的余数归最后一批；每笔批次合计等于计划金额。期外释放仍显示，不删除本金。

## 计划不等于现金或收益

展示的是计划本金合计、计划到账日期和批次，不填写预期年化或生成无数据的十年收益。保存不创建 portfolio/account、现金、成交、预占、审批或执行；不改变研究权重、观察模型单位或 NAV，也不替用户确认风险预算。

三批的 60 日只约束释放日期，不保证成交完成，更不是最低价择时。预计资本只有在后续明确的反事实研究内才能按假设到账处理；这仍不是实盘到账事实。

原偏好的可选预算可作为第一次编辑的可见预填，但需用户点击保存。投入记录独立于示意预算；修改偏好不会悄悄更改已存金额或日期。任何偏好版本变化都将计划标记为需要重新审阅，修订保存后重新绑定当前版本。旧版本不覆盖或删除。

## 证据与权限

迁移 35 追加 `investor_funding_plans`，固定所有者、偏好 ID/哈希、计划内容哈希、顺序版本与审计。共享封闭合同为 `contracts/v1/investor-funding-plan.schema.json`；Web 与 Python 独立生成同口径计划日期和分批金额。

保存复用认证、Origin、会话绑定、32 KiB 输入、严格 JSON、工作区 CAS 和幂等收据。响应丢失时重试原请求，不新建一条假定失败的请求；恢复只读禁止新保存和已成功请求的写重试。编辑投入安排时暂停其他研究操作和轮询，避免后台刷新覆盖表单。

读取核对内容、元数据、偏好和原命令审计，再生成日期表；前端重新生成整份表，拒绝伪合计、伪日期和错误的当前偏好标记。可选投入证据损坏时显示不可用，不覆盖历史，也不阻断独立研究资料。三个字段始终为 false：

```text
actual_arrivals_confirmed
execution_authorized
live_advice_eligible
```
