公开费率文件不能补造历史费率路径或在当时已知的资料。当前重建器不额外重复扣除已经反映于净值/价格的基金运营费；券商佣金、点差、换汇、税务和交易失败另行建模。发行人 FAQ 中的交易税提示仍需和当前适用规则独立对照，本轮没有据其填入税率或免税假设。

## 3. SDK 请求核对

工程记录的源提交 `72e9be585d2724358ddaf7d6afbb64bb9e01205d` 下，[Python 包装](https://github.com/longportapp/openapi/blob/72e9be585d2724358ddaf7d6afbb64bb9e01205d/python/src/quote/context.rs#L320-L343)直接转发 symbol、周期、复权、起止日期和时段；[Rust 历史请求](https://github.com/longportapp/openapi/blob/72e9be585d2724358ddaf7d6afbb64bb9e01205d/rust/src/quote/context.rs#L943-L993)使用按日期查询，日期编码为 `YYYYMMDD`，返回向量逐项转换而不是静默过滤失败项。与[官方历史接口参数](https://open.longbridge.cn/zh-CN/docs/quote/pull/history-candlestick)未发现明显参数冲突或 A 股特定日期过滤分支。

这是静态核对，不是线上的原始响应捕获，也不证明安装二进制逐字来自该提交或 SDK 没有其他问题。没有足够证据直接升级 SDK、改端点或放宽校验。下一步应核对特定 ETF 的服务覆盖，必要时评估独立历史来源；不自动改用净值、指数或复权价冒充可交易 ETF 收盘价。

## 4. 从候选到合格目录的剩余工作

1. 核对更新产品公告、结构、挂牌/退市生命周期、交易单位与账户可买性。成立日不能代替上市日，上市日期也不是完整 UTC 交易时刻证明。
2. 完整的历史/当前价格、公司行动、分红及可重放总收益；按市场核对交易/交收日历。两根日线或一张年度表现图都不足以研究十年资金路径。
3. 人民币单位正确、有可用时点的 FX 和实际成本/税务假设；美元债券不能未经汇率压力测试就当作人民币防守资产。
4. 独立核对成分重叠和集中度。多个交易市场、多个代码和全球股票基金叠加，不自动等于更分散。
5. 私有研究/留存/展示/备份的适用资料；外部 AI 共享另行确认，不从公共产品资料或 API Key 推断行情授权。
6. 当前来源审阅、风险预算、策略/基准验证，以及正常、新资金、陈旧三条持续监测纵切。候选文件不能绕过既有准入或产生个人目标。

`node scripts/check-etf-source-candidates.mjs` 只检查字段、日期、映射、费用表示和“非合格”边界；它不访问网络/数据库、不认证原件真实性、不选择或批准策略，也不能替代上述工作。

候选元数据专项 5 项、既有研究事实校验入口的拒绝专项 2 项通过：整个候选文件不能作为任何已审阅事实类别，六个候选也不能直接成为挂牌事实。验证仅调用纯校验，不创建批准记录、访问数据库或调用行情服务。证据位于 `artifacts/verification/etf-source-research/2026-10-08/verification-summary.json`，不是完整运行时、界面或发布验收。
