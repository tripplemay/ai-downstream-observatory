# 长桥 AI 工具：无需手工 API Key 的行情接入

状态：2026-10-07 官方页面、CLI/MCP 文档及本地 CLI 帮助核验；独立本地 CLI 的 OAuth 登录、三地各一个 ETF 的报价和短窗口日线读取已完成。本文不证明完整三地数据覆盖、报价时效、长期稳定性、许可留存或生产准入。

本文使用通用配置与示例，不记录账户、密钥、Token、设备授权短码或私人行情样本。行情源总体选型与数据门槛见 [10](10-market-data-source-selection.md)。

## 1. 修正接入前提

长桥当前提供 ChatGPT App、托管 MCP、CLI、AI Skill 和支持 OAuth 的 SDK。官方首页明确 AI 接入可通过 OAuth 授权，不需要用户手工提供 API Key。[官方首页](https://open.longbridge.com/zh-CN)

因此：

- 现有旧 `longport==4.3.7` 适配器需要传统 App Key、App Secret 和 Access Token，是**该适配器**的前提，不是长桥所有行情工具的统一前提。
- 新 CLI 的 `auth login` 可以完成 OAuth 设备授权；凭据由程序维护，不要求补齐传统 API Key 配置。[CLI 安装与登录](https://open.longbridge.com/zh-CN/docs/cli/install)
- 托管 MCP 使用 OAuth 2.1；无需用户把 API 密钥交给 AI 客户端，但仍需要登录授权，且工具可用范围受地区、账户和 scope 影响。[MCP 接入](https://open.longbridge.com/zh-CN/docs/mcp)

**无需手工 API Key 不等于匿名、无凭据、全部市场实时免费或已获得永久留存授权。** OAuth 仍会产生由客户端维护的凭据；实际数据权益和用途条件继续核验。传统 Access Token 也不能直接替代 OAuth Token。

## 2. 工具如何分工

| 路线 | 适合的工作 | 本工程边界 |
| --- | --- | --- |
| 官方 CLI + OAuth | 可重复的本地行情验证、JSON 输出、后续受控服务器采集 | 已有独立检查入口；不调用账户、订单、资金或其他写接口 |
| 传统 API Key + SDK | 通过私有环境文件注入后台行情容器 | 独立路线，见 [API Key / VPS 接入](12-longbridge-apikey-server-access.md)；不调用交易或账户接口 |
| 托管 MCP + OAuth | AI 会话中的行情检索和交互研究 | 可选辅助，不直接暴露完整工具集给组合监测调度器 |
| ChatGPT App | 人工问答与快速观察 | 会话中的授权不自动成为本工程后台授权，也不是持续采集已实现 |
| AI Skill | 指导 AI 使用相应工具的文档 | 不是独立匿名行情源；安装 Skill 本身不能代替连接和授权 |
| 新 OAuth SDK | 长期供应链的专用适配器候选 | 另行锁定版本、认证生命周期与只读合同，不直接升级现有生产依赖 |

官方 CLI 提供机器可读输出，适合先证明一条窄的读行情路径；这不表示其自身只有读能力。[CLI 概览](https://open.longbridge.com/zh-CN/docs/cli)

采用 CLI 作为验证入口的工程理由是：不用先全局配置 MCP 或安装所有交易相关 Skill，也不用为验证先改造生产 worker。后续选择 CLI 还是专用 SDK 应以认证维护、可靠性、可审计输出、批量限流及部署测试决定，而不是以“AI 原生”宣传代替验收。

## 3. 本地验证的最小流程

官方安装入口：

```sh
brew install --cask longbridge/tap/longbridge-terminal
longbridge --version
longbridge auth login
```

本轮实际没有执行远程脚本管道或全局 Skill 安装：从官方仓库发布包准备独立 CLI，校验官方 Homebrew cask 的 SHA-256，再查看离线帮助。验证版本为 `0.28.7`，macOS arm64 包的校验值为：

```text
2e723e1f1a2864cf01a8369dfffb68a4cf59c9382b847a89893c033c43bb72ac
```

校验依据为 [官方 cask](https://github.com/longbridge/homebrew-tap/blob/main/Casks/longbridge-terminal.rb)。版本与摘要仅证明本轮程序来源绑定，不证明其全部功能或无安全缺陷；正式部署需独立锁定和审查适用平台版本。

上述 SHA-256 是 **tar.gz 发布包**的摘要，不是解包后二进制的摘要。将已验证发布包中的 `longbridge` 成员流式提取并计算摘要，再与本地可执行文件核对，二者一致为：

```text
82168f35303355fb8305ae895889da59b5fbe97124952b15845377240e73bb4a
```

新的运行时检查固定此可执行文件摘要，不用发布包摘要验证二进制，也不接受用户随命令传入任意摘要来放行程序。

OAuth 登录使用独立私有 HOME、空认证环境和受控工作目录，不读取传统密钥文件、不复用其他软件的 Token。短码与授权页面只用于本次人机登录，不写公开文档或 CI。授权需由用户在长桥页面核对应用及权限后完成，agent 不代替用户点击同意；日志不回显 Token。

授权后才依次验证：

1. 登录完成和 Token 状态；输出仅保留必要状态，过滤账户标识和敏感字段。
2. 三地各一个 ETF 的最新报价，检查证券集合、价格、时间、状态和实际权限。报价示例仅用于连通验证，不构成标的推荐。
3. 相同标的的短窗口日线，固定 `day`、`none`、`intraday` 口径，核对日期、数值、缺行与休市情况。
4. 按市场记录成功、权限不足、缺数据或陈旧，不因一个美国报价成功而宣称三地都通过。

示意命令，必须在实际授权后执行：

```sh
longbridge quote 510300.SH 2800.HK SPY.US --format json
longbridge kline history SPY.US --start 2026-09-21 --end 2026-09-25 \
  --period day --adjust none --session intraday --format json
```

`0.28.7` 本地帮助明确历史命令的起止日期必须同时提供；缺任一项会改为最近 100 根，不能称为指定区间回补。上述示例不是后台计划、长期历史验收或实际运行结果。

## 4. 只读与持续运行的工程要求

- CLI 与 MCP 同时有行情和交易能力。只允许固定行情命令/工具及固定参数构造，不接受 AI 生成的任意子命令、shell 拼接或 `--execute`；不安装 `longbridge *` 的全能力自动放行规则。只读行为不能冒充 OAuth 凭据已被服务端限制为只读。
- 未获相应授权不请求资产、持仓、成交、订单、资金流水或银行资料；行情验证也不创建自选股、定投、提醒或任何交易计划。
- 若授权页提供可选 scope，仅申请本任务需要的行情/研究权限；若强制包含额外敏感权限，先由用户明确决定，不自动扩大授权。授权应用名、撤销与过期状态纳入私有运维管理。
- CLI 的 OAuth 令牌刷新、重启、失效、并发及无人值守能力还需实际验证。个人电脑登录成功不等于生产 VPS 已授权；不把本地 OAuth 文件直接复制进镜像、公开仓库或 CI。
- 标准输出是 CLI 投影，不是供应商网络原字节。将其纳入研究供应链时必须绑定二进制版本/摘要、参数、调用时点和口径，新增明确来源合同；不能冒用现有 SDK 捕获类型。
- 最新报价与指定区间日线仅证明局部读取能力，不能替代分红、拆并份、总收益、历史 ETF 集合、穿透持仓、留存许可和持续故障测试。

行情数据的持久保存、备份和外部 AI 使用继续按 [行情源选型第 5 节](10-market-data-source-selection.md#5-授权与长期留证必须先解决的冲突) 单独核验。AI 只解释可验证结果，研究不写真实账本、不批准或下单。

## 5. 当前完成边界

已核实官方存在无需手工 API Key 的 OAuth 路线，并使用已校验的本地独立 CLI 实际读取行情。传统密钥文件未参与这些 OAuth 调用；OAuth 本身不要求补齐传统 Access Token。后续单独完成的 API Key 日线验证见 [12](12-longbridge-apikey-server-access.md)，两者不混同。

### 5.1 本地最小读取结果

调用时间为 2026-10-06 UTC / 2026-10-07 本地日期；版本 `0.28.7`，OAuth 使用独立 HOME 和空传统认证环境。登录流程返回认证成功，报价与日线命令均退出为 `0`、返回可解析 JSON。此处只记录测试方法和结果元数据，不记录价格原件、账户或凭据。

| 市场 | 连通测试标的 | 报价读取 | 指定窗口日线 | 市场当地日期 |
| --- | --- | --- | --- | --- |
| A 股 | `510300.SH` | 一个匹配记录，价格为有限正数 | 4 根 | 2026-09-21 至 2026-09-24 |
| 港股 | `2800.HK` | 一个匹配记录，价格为有限正数 | 5 根 | 2026-09-21 至 2026-09-25 |
| 美股 | `SPY.US` | 一个匹配记录，价格为有限正数 | 5 根 | 2026-09-21 至 2026-09-25 |

日线请求使用第 3 节的完整起止日期和固定口径；返回的市场当地日期在请求区间内、无重复且递增，OHLC 为有限正数、高低价关系及非负成交量通过基本检查。A 股 9 月 25 日缺行与上交所公布的中秋休市安排一致，不填零、不补造该日价格。[上交所休市公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20260915_10832273.shtml)

本轮发现并修正了验证脚本的两个投影假设：实际 JSON 报价字段为 `last` / `status`，不能按旧 SDK 的 `last_done` / `trade_status` 匹配；日线 `time` 使用带 `Z` 的 UTC 时间，必须分别转换为 `Asia/Shanghai`、`Asia/Hong_Kong`、`America/New_York` 的当地日期，不能截取 UTC 字符串前十位作为交易日。重新调用同一有界窗口后，上述基本检查通过。正式适配器需针对这些合同差异建立合成回归测试。

报价 JSON 没有源行情时间戳；本轮仅知道请求时间，不能把有效价格或 `Normal` 状态当作当前实时行情的证明。三个标的、短窗口、基本数值检查也不证明价格准确性、全部 ETF 权限、完整历史或策略输入已合格。请求输出在内存中处理，未导入工作台数据库或保存行情原件。

### 5.2 仍需完成

报价时间与延迟权益、交易日历、代表性数据的交叉核验、分红/拆并份及总收益口径、适用留存与外部 AI 条款、OAuth 生命周期和生产 Linux 接入须另行验证，再决定专用 SDK 或 CLI 适配器及上线边界。

本轮没有全局安装 Longbridge Skill、配置完整 MCP 工具集、修改旧 SDK、读取持仓/资金/订单、下单、重启服务或切换生产行情源。工具介绍、安装、认证和少量读取成功都不能冒充数据源已合格。

### 5.3 受控工程入口

新增 `worker/market/providers/longbridge_cli.py` 和 `python -m worker.market inspect-longbridge`，只接受固定行情读取和指定日线窗口，不接入原有 SDK 价格批次、数据库或调度。使用方法与限制见 [market 模块说明](../worker/market/README.md#isolated-longbridge-oauth-inspection)。这是内部数据接入检查，不是要求普通用户填写 JSON 或建立账本后才能查看组合的新主流程。

纯解析器校验准确证券集合、价格的精确十进制、成交量、UTC 时间到市场当地日期的转换、区间、顺序和调用者给定的日期覆盖。只读执行器校验固定平台、版本与二进制摘要，私有复制后执行；不继承传统密钥、代理、任意服务地址或数据库环境。调用有独立超时和输出上限，供应商诊断仅转换为固定错误码。OAuth 本地状态可能由 CLI 刷新，检查器不回显账户或 Token。

命令输出仅为检查元数据，不输出或保存行情价格。`sample_read_ok` 不能代替报价时效、交易日历、ETF 身份、许可、总收益和生产准入；未验证字段保持未验证。测试全部使用合成数据和隔离临时目录，不需要供应商凭据，也不替代真实调用验收。

该工程入口已在独立 Python 3.11 环境中执行三地实际 OAuth 读取：第 5.1 节的三个标的均返回 `sample_read_ok`，报价各一个记录、日线分别为 4/5/5 根，日期与固定预期集合匹配。将 A 股同一窗口的预期集合仅新增休市日 2026-09-25 后，返回固定错误码 `LONGBRIDGE_EXPECTED_DATE_COVERAGE_MISMATCH`、退出为 `1`，不返回部分成功或补造行情。适配器仍未注册为生产数据源。

测试覆盖 JSON 重复键/非有限数/体积限制、精确价格和 int64 成交量、三地日期与美国 DST、缺行/重复/额外/乱序/当前日阻断、私有 HOME、版本/二进制来源校验、环境隔离、诊断脱敏、输出上限、父进程与内核超时、固定命令集合，以及 CLI 的零数据库访问和无交易参数透传。市场 Python 回归和共享合同测试分别运行，结果见本轮交付说明；测试依赖使用仓库现有锁定版本，不替换原 `.venv` 或生产运行时。
