# 已发生外部资金的直接回录

状态：本地研发，尚未发布。仅补齐 P2 的少量外部入金/出金事实入口；不代表完整账户级建议、证券成交/交收、估值和执行复核已经完成。

## 使用路径

1. 在“账户资料”选择自己的私有账本和本次回录账户。新建空账本只建立元数据，不把研究预算或投入计划记成到账。
2. 点击“录入已到账或已转出资金”。系统只核对账户与版本；方向、币种、金额、日期、时区、来源标识和原流水编号均不预填。
3. 按独立资料填写外部入金或出金、CNY/HKD/USD 原币本金（不含费用，最多两位小数）、实际日期和资料时区，以及来源标识、唯一编号及说明。
4. 明确确认后保存。改动任何字段会清除确认；保存是转录已发生事实，不会发起转账、换汇或券商订单，也不会确认未来计划资金已到账。
5. 重新录入独立资料对账；旧对账或估值不能证明新增事实后的当前状态。估值仍须通过高级账本生成与核对，本入口不自动推导完整组合收益。

内部账户互转、换汇、成交交收、费用和期初余额不在此简化入口处理，应使用相应事实与高级账本复核。不得把这些记录再次计入外部本金，亦不得用零或计划金额填补未知历史。真实已发生的出金不等同于可用资金检查或交易授权；不通过补造历史现金让转录通过。

如果页面提示“这次提交仍待核对”，先保留原请求。明确点击“核对并重试原请求”会恢复相同请求与幂等键；不要因为网络失败另换流水编号重复入账。只读取最新记录不是原请求失败的证明。

## 实现边界

- 新增只读 `GET /api/workbench/investor/cash-recording?account=...`；要求当前认证会话和强制会话绑定，仅返回账户/关联/版本元数据，无余额、预算或事实预填。GET 不写账、不调用供应商或 AI。
- 写入采用独立封闭动作 `record_linked_cash_fact`，复用 `POST /api/workbench/investor` 的同源、严格 JSON/32 KiB、二次会话核验、工作区 CAS、不可变收据和原子审计。既有成交动作的合同不扩大。
- 同时核对账本、关联及其版本、账本事实版本、账户行版本和上下文摘要；停用账户、恢复只读、过时范围和未来事实不允许写入。超过 10,000 条账本历史事件时转人工复核，不把截断结果作为完整范围。
- 复用现有 `recordFact` 的精确字符串分录、时间顺序、来源去重、投影和对账失效逻辑。入金增加已结算现金并等额减少 `external_capital`；出金相反，不将本金当作收益。
- 原来源及语义一致的重复回录复用既有事实；不同金额等语义冲突拒绝，被修正的原来源不能复活。金融来源去重与命令受理收据是不同层级；后续 CSV 必须保持原始来源、时间精度、时区和事实语义，不承诺跨来源自动识别重复。
- 草稿期间锁定账户切换、CSV、新对账、成交草稿、组合数字和顶层刷新。取消清除草稿；会话失效或范围变化清除私人输入并隔离迟到响应。提交仅交给既有父级未知响应恢复流程，不增加自动 POST/重试。
- 不新增迁移，不写证券、策略批准、激活、预占、执行报告、研究方案、投入计划、AI 请求或后台任务，不向外部模型发送现金或独立资料原文。

## 验证与复现

限定 Web 回归已通过 103 项，覆盖资金/成交、账户/持仓、独立对账、共享显示与会话事件边界；完整 TypeScript 检查通过。它们不能代替当前提交的全量 CI、真实界面或生产验收。

实际认证 HTTP 回归在 `web/scripts/investor-http-cases.mjs` 的 `HTTP-I21` 使用独立虚构账本，核对三币种入金/出金、精确分录、原样重试、来源冲突、恢复只读和研究/交易权限不变。浏览器专项为 `tests/investor/browser_cash_recording.py`，只接受临时 fixture 库；使用真实 Next 生产构建与认证路由，并在一次真实提交后主动丢弃响应以核对恢复。运行结果和截图归入私有 `artifacts/verification/`，不公开真实资料。

认证 HTTP 专项 27 项通过，使用本轮生产构建，最后仅无障碍选择器名称发生界面变化；该 HTTP 结果不重新认证后续所有源码。最终 headless Chromium 专项 22 项通过，构建 `TG2TTU986VHLALyOICt6L`，期间被核对的源码未变化，零 JavaScript 页面错误。实际完成空账户独立对账、空白资金草稿/范围锁、取消、三币种资金及出金、一次真实已提交但响应丢失后的相同字节重试、独立三币种对账和重载保留，并检查桌面/390px 无横向溢出；没有用模拟成功响应代替服务器写入。测试库只有 4 条资金事实、8 条分录，证券/审批/激活/预占/执行报告均为零；六张截图中的空白草稿手机、待核对桌面及已对账手机已实际查看，不作为整页人工批准。
