# ETF 投资工作台：数据与组合核算规范

版本：v1.1 | 日期：2026-09-12 | 状态：公开核算规格与合成样例

上位依据：[01 投资目标与约束模板](01-investment-mandate.md)、[02 产品需求](02-product-requirements.md)、[03 决策治理](03-decision-policy.md)。实现边界见[05 架构与迁移](05-architecture-and-migration.md)，验证样例见[06 验证与验收](06-validation-and-acceptance.md)。

本文的核算规则是通用实施与验收规范，不是个人账本或税务申报规范。金额、价格、日期和阈值样例均为独立合成测试数据，不表示任何人的预算、实际资产或投资推荐。各组合按 01 模板在本地维护 D-01 至 D-08 的状态；采用本规范不代表账户资料已核实或交易获批。

## 1. 核算边界与不变量

### ACC-01 规划、事实、投影分层

- 规划层：本地填写的初始来源、日期化追加和预计提款计划；不产生现金、成交或收益，不预置金额或到账日。
- 事实层：确认的期初余额、资金流水、成交、公司行动、费用与更正。
- 投影层：根据某个事实版本和市场数据版本计算的持仓、现金、净值、收益与风险。
- 研究层：回测、建议跟踪、前向模拟，必须带独立 `environment` 和 `run_id`，不能写入真实事实层。
- 已发布历史投影不原地覆盖；事实更正后生成修订版本，保留“当时已知”和“按最新事实重述”两种视图。

必须始终成立：预算不入账；批准不成交；入金不是盈利；内部调拨不增加总组合本金；结算不重复增减资产；缺失估值不按零；原始数据和批准依据可追溯。

### ACC-02 组合范围

`portfolio` 管理纳入范围的所有账户、币种、持仓、在途资产、应收应付和现金。账户别名与实际身份分开保存；账户可同时支持多个市场。人民币为总组合评价币种，原币事实永久保留。

完整历史缺失时，以经用户核对的期初状态建立 `performance_inception_at`。期初市值是起算权益，不伪造当年入金或历史成本；已知历史成本单独记录。界面分别显示“起算权益”“起算后净投入”“自起算日损益”，历史总投入未知时不能显示全生命周期盈利。

## 2. 标识、精度与时间

### ACC-03 证券标识

| 字段 | 规则 |
|---|---|
| `instrument_id` | 内部不可变 ID，不用展示名称作主键 |
| `listing_id` | 唯一上市份额 ID；绑定市场、交易所及证券代码 |
| `ticker_aliases` | 带来源及有效区间的代码映射，保留前导零和后缀 |
| `fund_id/index_id` | 基金与跟踪指数关联；不同上市份额不自动视为可互换 |
| 分类 | 上市市场、注册地、底层地区、资产类别、计价币种和风险暴露分开 |
| 可交易信息 | 数量步长、价格步长、结算规则及账户权限均版本化，未知时禁止形成有效交易数量 |

交易单位不全局硬编码为 100 股；是否支持碎股、具体交易/结算规则以已验证的市场和账户配置为准。不假设任何具体券商的账户权限。

### ACC-04 数值表示

- 事实金额、费用、数量、价格、汇率以规范十进制字符串传输和存储；禁止经 JavaScript `number` 或 SQLite `REAL` 中转后声称无损。
- 建议单个字段最多 38 位有效数字、18 位小数；运算精度至少 50 位。超出范围保留原文并隔离，不静默截断。
- 原始输入、标准化值、单位和小数精度分别可追溯；负号、括号、千分位和币种必须显式解析。
- 现金确认量子、成交数量步长、价格步长按来源/证券配置。券商已给出的结算金额优先作为事实，`数量 × 价格` 仅用于核对。
- 只在实际结算或契约指定的边界舍入；默认计算舍入采用 half-even，若券商口径不同，配置并留痕。
- 展示保留两位小数不改变底层精度。不可解释的差额进入对账问题，不用“调整项”静默抹平。
- 统计分析可用浮点，但进入金额或交易数量前必须返回受检的十进制路径；账本和统计结果的容差分开。

SQLite 浮点是近似表示，故不以 `REAL` 作为财务事实的唯一精确来源。[SQLite：Floating Point Numbers](https://www.sqlite.org/floatingpoint.html)

### ACC-05 时间语义

每项事实/数据按用途记录：

| 字段 | 含义 |
|---|---|
| `effective_at/trade_date` | 经济事件实际发生时点或交易日 |
| `settlement_date` | 实际/预计结算日，二者分字段 |
| `published_at` | 来源首次公开时间；未知不得填成报告期末 |
| `observed_at` | 行情观测时间或基金持仓披露基准日 |
| `ingested_at` | 本系统实际获得原始资料的时间 |
| `recorded_at` | 事实经确认进入账本的时间 |
| `revision_id` | 来源修订或系统更正版本 |

时点统一保存 UTC，并保留来源时区；只有日期的记录保存 `time_precision=date`，不伪造分秒。业务日期不能由服务器时区隐式推导。

真实决策重放只能读取其决策时已进入系统且当时有效的数据。历史研究若使用有可信历史发布时间及修订档案的资料，标记为 `historical_point_in_time`；没有该证据的回填只能标记 `reconstructed`，不能冒充当时系统已知。两类模式不可混淆。

## 3. 事实账本与交易日记账

### ACC-06 事件与分录

采用追加式经济事件、逐币种平衡的金额分录，以及独立的证券数量变动。不是完整法定会计或税务账簿。

最小事件字段：`event_id, portfolio_id, account_id, environment, event_type, effective_at, recorded_at, source_id, source_event_id, idempotency_key, payload_hash, reversal_of, transfer_group_id, execution_item_id, schema_version`。更正理由、批准身份及附件引用不得缺失。

分录建议使用借方正、贷方负；每个事件的每个币种分录合计严格为零。证券数量通过 `position_movements` 单独平衡来源，不把股数与货币相加。

| 账簿科目 | 用途 | 纳入市值资产方式 |
|---|---|---|
| `cash_settled` | 已结算现金 | 按原币现金计入 |
| `trade_receivable` | 已卖出未结算应收 | 计入资产，但首版不作已结算可用现金 |
| `trade_payable` | 已买入未结算应付 | 作为负债扣除 |
| `dividend_receivable` | 已确认分红权益尚未支付 | 计入应收，支付时转现金 |
| `transfer_in_transit` | 已出账但仍归本组合所有的在途资金 | 总组合只计一次，不能用于新买入 |
| `inventory_cost` | 证券记账成本 | 估值时用数量乘市价替代，不与市值重复相加 |
| `external_capital/opening_equity` | 外部投入、退出及期初权益对方科目 | 不作为资产重复计入 |
| `income/expense` | 分红、利息、已实现损益、显式费用 | 用于解释损益，不与资产再次相加 |
| `fx_bridge` | 跨币种换汇的逐币种平衡桥接 | 不纳入资产，必须关联同一换汇事件 |

投影缓存可更新，但从事件和分录全量重建必须得到相同结果。所有一组分录、数量变动、幂等键、账本版本及审计记录在同一事务提交。

### ACC-07 事件处理表

| 事件 | 处理 | 不得发生的行为 |
|---|---|---|
| 外部入金/出金 | 现金与外部资本对记；记录现金流所属评价范围 | 当成利润或只修改显示本金 |
| 期初建账 | 现金/持仓/应收应付与期初权益对应 | 伪造历史成交；预算自动变为期初现金 |
| 买入成交 | 成交日增数量、增成本、确认费用和应付款 | 等结算才认持仓，或同时减现金又重复扣应付款 |
| 买入结算 | 减现金、冲应付款 | 再增加证券或再扣费用 |
| 卖出成交 | 成交日减数量及成本，确认应收、已实现损益和费用 | 继续把卖出证券计入市值 |
| 卖出结算 | 增现金、冲应收款 | 再确认一次卖出收入 |
| 费用/扣税 | 有来源的费用事件或成交分录组件 | 同时在成交净额和独立费用中重复扣除 |
| 分红/利息 | 确认权益或到账，区分毛额、扣税、净额和状态 | 把分红作为外部入金 |
| 换汇 | 两币种资金腿与桥接，显式手续费单独记录 | 当成新投入或按参考汇率覆盖实际汇率 |
| 内部转账 | 出账转在途、入账冲在途；关联双方及手续费 | 出入两腿均增加总组合本金 |
| 拆分/合并 | 变更数量及单位成本，总成本不变 | 无现金事件却制造损益 |
| 证券转入/转出 | 区分组合内调拨与组合外实物资金流 | 没有成本资料时猜测已实现收益 |
| 撤单/建议取消 | 释放相应未成交预留 | 删除已发生的成交 |
| 更正 | 追加反向事件与替代事件，重算受影响投影 | 原地修改已确认事实或批准证据 |

只有券商结算摘要、没有交易日资料时，可在同一已知日期原子录入成交与结算，但标记历史时间不足；不推断中间日期的精确收益。

### ACC-08 可用资金与预留

首版不以未结算卖出款、未来入金或预计转账支持新买入。即使券商实际提供更宽的购买力，也只能在另行验证并批准规则后使用。

对账户币种计算：

```text
available_cash = settled_cash
               - unsettled_buy_payables
               - confirmed_other_cash_holds
               - active_unfilled_buy_reservations
```

这是保守执行预算，不是净资产公式。确认现金冻结项应去重，不能把同一笔券商冻结与工作台预留扣两次。成交产生应付款时，同事务释放对应预留；数量和价格差异触发重算。卖出也要预留证券数量，防止多条清单重复出售。

仅把“工作台内已批准或用户报告已下单”的未成交项目预留；账户外操作未知时必须核对券商可用资金。预留是执行状态，不是经济损益分录。

## 4. 成本、分红、换汇及转账

### ACC-09 成本与损益政策

管理账本采用每账户、每证券、原币移动加权平均成本，显式交易费用当期费用化；此口径不是税务成本法。券商税务成本/税批信息另存，不覆盖管理成本。

```text
买入后单位成本 = (原数量 × 原单位成本 + 买入成交本金) / 新数量
卖出毛已实现损益 = 卖出成交本金 - 卖出数量 × 卖出前单位成本
剩余未实现损益 = 剩余数量 × (估值价 - 当前单位成本)
```

买卖费用已计入现金或应付/应收及费用解释项，不再次从净资产或上述净值收益扣除。未知成本影响已实现/未实现拆分，不必然阻止已有可信起算市值后的总组合收益；不能用总收益反推缺失历史成本。

### ACC-10 分红与公司行动

- 按可信权益数据在除息后的对应时点确认应收分红，避免除息降价被误当成全部亏损。
- 例：1000 份、价格 10，除息后 9.8，毛分红 200、已确认扣税 20，则市值 9800 + 净应收 180 = 9980；20 是税费影响。支付后应收转现金，不再次确认收入。
- 税率/扣税未知时保留明确的暂估状态与范围；确认后追加差额，不假装已得到最终税后收益。
- 若无法确认分红权益，相关日期表现标为暂估或不可用于精确评价，不能仅因原始收盘价可用就判为完整。
- 自动再投资需记录“分红支付”和“再投资成交”两类事实；不按凭空增加数量处理。
- 拆分例：100 份、单位成本 20，1 拆 2 后为 200 份、单位成本 10，总成本仍为 2000。
- 基金合并、清盘、资本返还等复杂行动先隔离并人工核实；未实现解析时不能错误归类为普通分红。

### ACC-11 汇率与跨账户调拨

参考汇率方向固定为 `CNY_per_unit_currency`，CNY=1；明确来源、观测时间和修订版本，缺 USD/HKD 汇率时不能默认等于 1。

实际换汇记录原币付出、目标币收到、实际费用及成交汇率；人民币评价另用同一估值批次的参考汇率。`fx_bridge` 逐币种平衡，跨币种桥接的参考人民币差额作为换汇执行影响解释，不能再生成一笔虚构现金费用。

同币种内部转账的金额腿在总组合不是外部资金流；在单账户绩效范围则是流出/流入。手续费仍是总组合费用。已出账未入账资金只有在有归属证据时计入在途一次；对手或归属不明时标记异常，不复制到两个账户。

境外账户是否可入金、兑换、转账不由系统推断。实际发生的事实照实记录，未来执行依赖则必须确认。

## 5. 估值、市场数据与来源质量

### ACC-12 净资产

以一个明确 `valuation_cutoff_at` 和事实版本计算：

```text
NAV_CNY = Σcurrency FX(currency) ×
          [settled_cash + trade_receivables + dividend_receivables
           + owned_transfers_in_transit - trade_payables - other_liabilities
           + Σinstrument(quantity × unadjusted_market_price)]
```

预留现金仍是资产，不从 NAV 扣除；`inventory_cost`、收入费用科目和外部资本科目不重复加入 NAV。一个资产只能属于一个估值位置。

统一截止时点前，各市场使用其已完成且可获得的最近有效交易时段数据；保留每个证券的实际价格时间。不得以 `MAX(px 日期)` 要求所有市场有相同自然日，也不得声称非同步收盘价是全球同时可成交价格。

质量分为 `complete`、`provisional`、`blocked`：

- `complete`：该批次必需持仓、现金、公司行动、汇率和日历均满足获批规则。
- `provisional`：可展示最近可信估值及缺失范围，不能作为完整净值或实盘放行依据。
- `blocked`：没有可靠估值基础，只展示已知部分和缺口，不给出虚假完整总额。

图表不得无标记跨接缺失区间。风控/评价是否容许某类暂估必须事先明确；默认不允许。质量覆盖率不能代替对关键持仓和依赖字段的逐项检查。

### ACC-13 市场数据契约

每条数据保留证券/指标、来源、单位、原始值、标准化值、观察时间、公开时间、获取时间、价格口径、修订号、原始资料哈希和解析版本。

- 原始未复权价格用于实际估值及成交验证；总收益/复权序列用于特定研究，并明确调整因子及版本。
- 已使用含分红的总收益序列时，不再额外叠加同一分红；不同价格口径不能覆盖到同一个无区分的键。
- ETF 全市场清单以抓取批次发布：记录预计分页、实际页数、去重数、覆盖范围、失败页和检查结果。
- 空返回或分页不完整不得将未返回 ETF 标记退市；停用必须是独立、有证据的生命周期事件。
- 策略排名在冻结的候选范围及所需数据完整后计算；没有获批降级规则时，不得因缺数据临时缩小范围并照常排名。
- 单数据源异常先隔离；来源替换需要口径对照。保留旧可信数据但标记时效，不把抓取时间更新成数据观察时间。
- 财报、ETF 持仓、价格、汇率的刷新周期和质量阈值分别配置。未知日历或缺失阈值禁止相关实盘建议。
- 基金持仓穿透报告披露日期及覆盖比例，未覆盖部分独立显示为未知，不能声称已全面分散。

## 6. 收益与风险计算

### ACC-14 外部资金流与绝对损益

总组合口径下，外部投入为正 `F`，提取为负；买卖、分红、费用、换汇、内部转账不是外部资金流。组合外证券转入按已确认市值计入外部实物流。

```text
起算后损益 = 当前净资产 - 起算权益 - Σ起算后的外部净投入
```

外币投入按实际发生时的可信参考汇率记录人民币流量，后续汇率变化为投资表现的一部分，不把历史本金随当前汇率重译。

### ACC-15 TWR 与估算口径

精确 TWR 在每次外部资金流前后切段。令 `V_i^-` 为流入前资产，`F_i` 为外部净流入，`V_i^+ = V_i^- + F_i`；下段收益为 `r_i = V_(i+1)^- / V_i^+ - 1`。首尾段按同样原则处理：

```text
TWR = Π(1 + r_i) - 1
```

例：起始 100，流入前涨至 110，追加 50 后为 160，期末 176，则 `TWR = 1.1 × 1.1 - 1 = 21%`，绝对损益为 26。仅除以起始本金或累计本金均不是该 TWR。

没有流入时点估值时，使用标记为 `modified_dietz_estimate` 的分期估算，不冒充精确 TWR：

```text
w_i = (period_end - flow_time_i) / (period_end - period_start)
r_MD = (V_end - V_start - ΣF_i) / (V_start + Σw_i × F_i)
```

只有日期的资金流建议采用评价时区的日终假设，报告 `date_only_eod_assumption`；不伪造真实时点。时段长度按实际时间或明确日期假设计算，不能两者混用。上述 100/50/176 例，若投入在区间中点，估计收益为 `26/125 = 20.8%`。

分期收益可连乘，但链中任一段为估算，整段须标为估算；有效分母不为正或存在无法解释的负资产时不给出普通收益率。首次建账、全额提取后重建等情况分别开收益区间，不跨零净资产强行连乘。精确 TWR 需要现金流时点估值，Modified Dietz 是估计方法。[GIPS：计算方法说明](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)

### ACC-16 资金加权收益/XIRR

采用投资者视角：投入为负、提取为正，在评价日追加当前净资产作为终值正现金流；期初权益在起算日视为投入，但标明只评价起算后表现。

```text
Σ C_i / (1 + r)^((date_i - date_0)/365) = 0, r > -1
```

日期按统一评价时区生成，排序并合并同日流量；先完整保留事实，再聚合计算。ACT/365 固定年长度与 Excel XIRR 常用口径对应。[Microsoft：XIRR](https://support.microsoft.com/en-us/excel/functions/xirr-function)

- 同日全部流量、缺少正负号、无根、多个根或不收敛，返回明确状态，不给出 0%。
- 常规仅投入且终值为正的情形采用括区间求根，保留残差及算法版本。
- 非常规现金流搜索潜在多根；不能仅返回默认初值找到的第一个根并称其唯一。无法可靠判定时返回 `ambiguous` 并展示现金流。
- 区间不足一年仍可显示 XIRR，但必须标“年化资金加权收益”和实际区间；不能称为已获得整年收益。

### ACC-17 回撤、基准与归因

- 回撤取剔除外部资金流的单位化收益曲线 `N_t`：`DD_t = N_t / max(N_s, s<=t) - 1`；最大回撤为最小 `DD_t`。
- 曲线采用估算收益时，回撤也标为估算；数据断裂期间不虚构低点或修复日期。
- 修复时间从对应高点到重新达到该高点；未修复显示持续中，不能记为零天。
- 有现金流时，不能对总资产首尾比直接年化。完整净值曲线的年化使用实际日数；短样本额外标识。
- 基准分别提供时间加权曲线和与真实组合同资金流的影子账户，费用、现金及执行规则必须显式定义。
- 滚动比较采用相同区间和币种，缺失日期不靠相同数组下标硬对齐；不能把不同起点的累计净值直接相减当成超额收益。
- 无资金流单资产例：原币收益 10%、对应货币对人民币升值 2%，人民币收益 `(1.10×1.02)-1=12.2%`，不是简单的 12%。
- 首版按原币资产价格、分红/利息、显式费用、汇率、换汇执行差和残差进行金额归因；交叉项单列。不能重复把已包含在成交价中的价差当作又一笔账本费用。
- 组合多期归因必须可对账，未解释残差显式展示并限制结论，不声称 AI 文本已经证明因果。

## 7. 导入、去重与对账

### ACC-18 导入契约

标准模板按事件类型分字段；共同字段为账户别名、事件类型、原币、来源记录号、有效日期、可选时点和备注。成交另需市场/证券、方向、数量、价格、本金、费用、净额、结算日期；资金需流入/流出性质与对手范围。

批次流程：原文件只读留存及哈希 -> 解析版本 -> 映射预览 -> 行级校验 -> 去重检查 -> 用户确认 -> 一批原子提交 -> 对账。任何未解决关键错误使该批保持预览状态；若用户选择有效行子集，应创建独立可追溯批次，不能静默部分入账。

两级去重：文件哈希防原件重传；`broker + account + source_event_id + event_type` 防跨文件重复。没有可靠来源 ID 时用规范化指纹标“疑似重复”，不能直接删除两笔金额相同的真实交易。相同幂等键但不同内容返回冲突，不覆盖历史。

### ACC-19 对账与更正

- 在相同截止时点逐账户、币种、证券比较数量、已结算现金、应收应付及券商可用资金。
- 券商展示成本与本管理成本不同可列为口径差异；数量或现金不符不得解释为正常收益差。
- 按来源精度核对金额；已验证舍入差须带原因和分录，数量不能以价格误差容忍。
- 更正经授权后追加反向及替代事件；迟到事实按经济日期重述投影，同时保留记录日期和旧报告。
- 对账未解决时阻断受影响账户或组合的清单，不阻止记录真实发生的交易。
- 原始文件、映射、解析器、幂等键、批准、入账和对账结果形成完整链条。

## 8. 核算金标准样例

以下独立样例使用人工构造数据，数值不绑定个人资金计划。它们定义测试预期值，保留固定值便于可复现核算；样例本身不代表系统已通过测试，执行证据另行记录。

| 编号 | 输入 | 精确预期或规定结果 |
|---|---|---|
| F-01 | 只录预算 80,000，无事实 | 资产/现金不能自动变为 80,000；尚未建账 |
| F-02 | 现金 64,000，确认入金 16,000，无价格变化 | 现金/NAV=80,000；本次入金损益=0 |
| F-03 | 初始现金 100,000；买 1000 份×10，费用10，先成交后结算，估值10 | 成交后持仓1000，应付10,010，NAV=99,990；结算后现金89,990，应付0，NAV不变 |
| F-04 | 接 F-03 已结算；卖400份×12，费用4，剩余也按12估值并完成结算 | 现金94,786；剩余600份市值7,200；NAV=101,986；毛已实现800+未实现1,200-总费用14=1,986 |
| F-05 | 1000份从10除息到9.8，毛分红200、已确认扣税20 | 市值9,800+净应收180=9,980；支付不再增加NAV |
| F-06 | 同组合A现金100,000、B现金0；内部转30,000，手续费另付10 | 出账后A=69,990、在途30,000；入账后B=30,000、在途0；总NAV均99,990，净投入不变 |
| F-07 | 现金7,007 CNY换得1,000 USD，显式费7 CNY，参考USD/CNY=7 | 剩余CNY=0；NAV=7,000；外部流量0；损益-7 |
| F-08 | 100 -> 流入前110 -> 追加50 -> 期末176 | 精确TWR=21%；损益26；中点Dietz估计=20.8%，二者标签不同 |
| F-09 | 2025-01-01投入100,000；2026-01-01终值110,000 | XIRR=10%，区间365日 |
| F-10 | 2025/2026/2027各年1月1日现金流-100、+230、-132 | 有10%与20%两个根，返回多解而不是默认择一 |
| F-11 | 单位净值1、1.2、0.9、1.08 | 最大回撤-25%，截至末点未修复 |
| F-12 | 同一已入账成交在另一文件重复出现 | 分录、现金、数量及费用均不再增加 |
| F-13 | 100份成本20，1拆2，除权价10 | 200份，单位成本10，总成本与市值均2,000 |
| F-14 | 原币资产收益10%，汇率收益2%，无现金流或费用 | 人民币收益12.2%，交叉项0.2个百分点 |
| F-15 | 两笔买入各预留60,000，账户可用现金100,000 | 不允许两笔同时获批；并发结果也必须满足总预留不超资金 |
| F-16 | 某持仓缺有效价格，另一个市场休市 | 按各市场日历识别；缺价不记0；不合格批次不生成完整收益或放行清单 |
