# 长桥历史同日重复记录修复

核对日期：2026-10-13。修复已完成专项验证，尚未切换生产服务，不代表完整组合研究可用。

## 1. 实际阻断点

对三只 A 股研究候选逐片检查时，`2021-12-14..2022-01-13` 窗口包含同日重复记录。重复日期为 `2022-01-04`；固定 `longport==4.3.7` 的只读 SDK 返回两条所有已接收字段完全一致的日线。原解析器将其视为同日冲突，终止连续历史采集。

更改查询窗口、拆分年份和排除假期不能消除此重复；因此没有修改交易日历或以特殊日期硬编码绕过问题。该观察只证明本次 SDK 响应包含重复投影，不证明上游网络包、SDK 或数据服务中哪一层产生重复。

## 2. 明确保留证据的 v2 投影

`worker/market/providers/longport.py` 的官方 SDK 路径现在可产生 `longport-candles-projection-v2`：

- 校验每一条记录的价格、成交额、成交量、时点及交易时段后再比较；只有同日的 **8 个规范化字段完全一致**才接受重复。
- 所有重复行仍保留在 `candlesticks` 原始顺序中，参与投影哈希。`duplicate_rows` 绑定重复行与第一行索引，同时记录原始行数与唯一行数。
- 研究观察只引用该日第一行的 `projection_row`，不重复计价。不同金额表示精度、时间戳、成交量或任何其他字段均不合并；缺日、额外日期、未来数据及行数上限仍拒绝。
- 无重复时继续生成字节兼容的 v1 投影。旧 v1 不获得重复豁免；不能把重复 v2 改标签后作为 v1 使用。
- 对外纯解析器及测试注入路径默认仍拒绝重复。新行为仅启用于固定 SDK、隔离 UTC 运行方式及相应证据重放，不新增 JSON/CLI 开关来绕过网络资格。

Python 子进程回放、市场采集提交回放与 Web 独立验证器均重新计算重复索引、行数及哈希，不仅信任生产方声明。伪造重复策略、计数或第一行索引，即使重算外层哈希，也不能通过回放。

“保留 SDK 投影行”不等于“保留上游网络字节”；`network_bytes_preserved` 仍为 false。公布日期、真实盘中可用时间与数据用途许可也不会因此获得认证。

## 3. 实测与来源准备

在不挂载数据库的 VPS 一次性只读容器中挂载修复候选，对 `510300.SH`、`511010.SH`、`518880.SH` 分别检查 `2021-10-13..2026-10-09`：

- 每只 59 个不重叠、最多 31 个自然日分片；每只 1,210 个唯一日期通过价格质量检查与暂定交易日集合比对。
- 每只响应包含 1 条完全相同的重复行；原始行仅在内存中验证，未作为价格收据或研究输入存入生产库。
- 暂定日历来源是交易所年度休市通知与周一至周五规则，尚未批准完整交收日历；该检查不证明真实账户可交易、企业行动完整或回测总收益正确。

新增 `worker/market/providers/sse_announcements.py` 对[上交所基金公告目录](https://www.sse.com.cn/disclosure/fund/announcement/)做完整分页投影：核对总数、页数、页内数据一致性、日期顺序、重复文件、证券代码及固定站内 PDF 路径。缺页、错误响应或范围外数据拒绝。标题分类仅筛选待读文档，不自动推断分红事件或“无拆分”。

三只候选的目录共 330 条公告，完整分页原文已私有保管。另补齐六个年度休市原文、五份国债 ETF 分红 PDF 与两份历史费率变更公告，相关分红单位、日期及费率已核对文本和页面。失败或不完整下载另行保留，不被覆盖或当作完整资料。

## 4. 验收边界

专项包含 Python 投影与 SQLite 提交/研究快照回放、Web 跨语言哈希/来源回放、旧 v1 兼容及冲突/伪造拒绝；这些测试不是完整工程 CI、界面验收或生产发布。

扩大本地回归结果：行情 Python 302 项、投资研究 Python 371 项、相关 Web 13 项均通过，无跳过；Web 类型检查与差异空白检查通过。测试样本仍为虚构资料，不替代下述真实凭据纵切或完整数据准入。

还以真实凭据在隔离容器中调用官方 SDK 子进程，经 Python 父进程规范化回放，再将该投影仅在内存中交给本机 Web 验证器独立重算。23 条原始行得到 22 条唯一观察，两端记录及投影哈希一致。该一次纵切不挂载数据库，不保存原始价格，不生成研究准入；SDK 临时输出位于一次性 tmpfs，不能表示为生产持久化验收。
